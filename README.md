# GO8-CHIP8

A CHIP-8 emulator built purely for personal enjoyment and to explore how the classic virtual machine works.

## About

CHIP-8 is a small interpreted programming language originally used for simple games. This project is a personal emulator implementation designed to load and run CHIP-8 programs.

## Features

- CHIP-8 instruction interpretation
- ROM loading
- Display and input handling
